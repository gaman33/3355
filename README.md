# WhatsApp 企业网页端 AI 翻译 + 智能客服（Chrome 扩展）

## 你关心的问题（先说结论）

如果你要做到：
- **全会话上下文理解（不只最近几条）**
- **可持续训练/维护客服知识库（产品、政策、报价、物流、售后）**
- **团队协作与质量管控（审核、追踪、统计、A/B）**

建议采用 **“浏览器扩展 + 后端应用” 的混合架构**，而不是只做纯扩展。

- 纯扩展：快，但数据、模型、知识库都在本地，难以规模化。
- 独立应用：能力最强，但接入 WhatsApp Web UI 需要额外集成。
- **混合架构（推荐）**：扩展负责贴合 WhatsApp 界面；后端应用负责长上下文、RAG 知识库、模型路由和运营分析。

---

## 本版本能力

- 自动识别客户号码（URL/标题提取）
- 区号推断国家/时区/默认语言，展示客户当地时间
- 自动识别客户语言并翻译成中文
- 默认你输入中文，翻译成客户语言
- 基于**全会话文本（可配置最大字符）**生成 AI 回复建议
- 支持导入知识库 JSON 条目，并在回复时检索相关条目优先参考
- 可自动查询账号可用模型并优先选择高等级模型（默认优先 `gpt-5`）

## 1) 安装使用

1. 打开 `chrome://extensions`
2. 开启「开发者模式」
3. 选择「加载已解压的扩展程序」
4. 选择本目录
5. 点击插件图标 -> 打开设置
6. 填入：
   - OpenAI API Key
   - 模型名称（建议 `gpt-5`，或你账户可用模型）
   - 是否自动选择最新可用优先模型
   - AI 客服语气
   - 上下文最大字符数
   - 知识库 JSON
7. 打开 `https://web.whatsapp.com/`

## 2) 知识库训练方法（轻量版）

在设置页 `知识库` 输入 JSON 数组，例如：

```json
[
  { "title": "报价规则", "content": "MOQ 100件，100-499件单价$9.9，500件以上$8.5" },
  { "title": "物流时效", "content": "DHL 3-5天，空运7-10天，海运25-35天" },
  { "title": "售后政策", "content": "签收后7天内质量问题可退换，需提供照片/视频" }
]
```

插件会根据当前会话文本做关键词检索，选出最相关条目注入回复提示词。

> 这是“可用”的训练方式，但不是企业级训练。企业级建议上后端做向量检索和版本化知识管理。

---

## 3) 何时必须升级为后端应用

当出现以下任一情况，建议直接上后端：

1. 单日消息量高，需要成本与延迟优化。
2. 多客服共享同一知识库、统一话术。
3. 需要对话审核、合规、权限分级。
4. 需要把 ERP/CRM/库存/订单系统接入回答。
5. 需要长期记忆（跨会话）与更可靠的 RAG。
